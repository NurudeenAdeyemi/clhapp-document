# Directory Overview

This directory contains the requirements documentation for a Training School CRM system. The central document is `REQUIREMENTS.md`, which outlines the various modules of the proposed CRM. The `docs` directory contains more detailed specifications for each module, with `ADMISSION_MODULE.md` being the first one.

# Project Overview

This project aims to define the requirements for a comprehensive CRM system for a training school. The system will manage all school activities, including admissions, academics, finances, and communication.

The proposed system consists of the following modules:

*   Admissions & Enrollment Management
*   Student Information System (SIS)
*   Timetable Management
*   Attendance Tracking
*   Fee & Financial Management
*   Learning Management System (LMS)
*   Examination & Grading
*   Communication Module
*   Parent/Guardian Portal
*   HR & Payroll Management
*   Inventory & Asset Management
*   Transport Management
*   Hostel Management
*   Alumni Management
*   Reports & Analytics
*   Certificate & Document Generation
*   Events & Activities Management
-   Online Registration Portal

The project also considers technical aspects like integrations, security, and performance. The MVP will prioritize the Student Information System, Admissions & Enrollment, Fee & Financial Management, Attendance Tracking, Timetable Management, Communication Module, and Basic Reports & Analytics.

# Module Details

## Admission Module

The Admission Module is the entry point for prospective students. It allows them to explore courses, apply for programs, and enroll. The module supports various learning modes, including cohort-based, virtual, and self-paced learning.

### Key Features:

*   **Course Catalog:** A searchable and filterable catalog of all available courses.
*   **Course Details Page:** A comprehensive page with information about a specific course.
*   **Delivery Mode Selection:** Allows users to choose their preferred learning mode.
*   **Cohort Management:** Enables administrators to create and manage cohorts for courses.
*   **Application Process:** A multi-step workflow for course applications, including user registration.
*   **User Registration/Signup:** Required for applying to courses.

The module also defines user roles, workflows, data models, API endpoints, and UI/UX specifications.

# Usage

The contents of this directory are intended to be used as a reference for the development of the Training School CRM. The documents provide a clear understanding of the system's requirements and specifications, and can be used to guide the design, development, and testing of the software.
